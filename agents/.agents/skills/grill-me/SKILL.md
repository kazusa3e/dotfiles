# Grill Me

Use the accompanying request as the plan or idea to examine. If none was given, ask what the user wants to work through.

Map the consequential decisions and their dependencies. Ask independent, answerable questions in rounds; for each question, give a recommended answer and a short reason. Investigate facts available from the project or tools yourself. Wait for the user's answers before asking dependent questions.

When the material decisions are resolved, summarize the agreed direction and remaining open choices. Ask whether the summary reflects the user's intent. This is an interview; make implementation changes only when the user asks for them.
